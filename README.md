# 🧮 Scientific Calculator (Python)

A terminal-based scientific calculator built using Python.  
This project performs multiple types of calculations in a menu-driven format.

---

## 🚀 Features

- ➕ Arithmetic Operations (Addition, Subtraction, Multiplication, Division, etc.)
- 📐 Mathematical Functions (Square root, Absolute value)
- 📊 Trigonometric Functions (sin, cos, tan, inverse functions)
- 🔢 GCD & LCM Calculation
- ⚙️ Logical Operations (AND, OR)
- 🧠 Bitwise Operations (&, |, ^, ~)
- 📏 Mensuration (Area & Perimeter of shapes)
- 📜 Calculation History
- 🧹 Clear Screen Option

---

## 🛠️ Technologies Used

- Python 3
- math module
- Basic control flow (if-elif, match-case)
- Loops and lists
- Exception Handling (try-except)
